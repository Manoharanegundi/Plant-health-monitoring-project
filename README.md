# Plant Health Monitoring System 🌱

An ESP32-based IoT project that monitors plant-growing conditions in real time and displays sensor readings through a Wi-Fi web dashboard.

## Overview

Developed as part of **Electrovista Club**, this project monitors soil moisture, temperature, humidity, and light intensity to help users understand plant-growing conditions and make informed plant-care decisions.

## Features

- Real-time monitoring of two soil-moisture zones
- Temperature and humidity monitoring
- Ambient light-level monitoring
- Wi-Fi connectivity and browser-based dashboard
- Sensor status indicators and plant-health score
- Historical sensor trends and plant-care recommendations
- Automatic dashboard refresh

## Hardware Components

- ESP32 microcontroller
- 2 × soil-moisture sensors
- LDR light sensor
- DHT22 temperature and humidity sensor
- Connecting wires and supporting circuit components


## How It Works

1. The ESP32 reads data from the connected sensors.
2. Sensor values are processed to classify soil moisture, light, temperature, and humidity conditions.
3. The ESP32 connects to Wi-Fi and serves a browser-based dashboard.
4. The dashboard displays readings, trends, a calculated plant-health score, and care recommendations.
